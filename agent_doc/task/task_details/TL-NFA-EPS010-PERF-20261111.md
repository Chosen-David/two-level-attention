# TL-NFA-EPS010-PERF-20261111

## 目标与口径

在用户指定的负向掉点扩展门禁通过后，只补测真正受 attention-mass threshold `0.05 → 0.10` 影响的 NFA 格，并重算 tail/full、skip/no-skip、NFA/FlashInfer 加速比。

- 模型 Qwen3-8B，RULER `niah_multikey_2` 固定 sample2；32K/64K/128K 为 native RULER，256K/512K 为 repeated-needle-body-extension 性能输入。
- 仅 CUDA Graph；12 个可行长度/batch 格，3 个容量不可行格只记录不运行。
- tail 严格为 L1/L2=`32/32`；full 严格为 L1/L2=`128/128`。此前误派的 full+same=`128/32` 新产物已隔离，未进入本汇总。
- 新治疗：dual near+far gate epsilon=0.10，`operator_mode=off`。no-skip 显式 epsilon=0；epsilon=0.05 仅作历史治疗对照。
- 算子使用独立 nsys CUDA Graph node trace，5 个 profiled decode steps；clean-E2E 使用无 nsys/profiler 独立进程，32 个 decode steps。两种时间不相减推导 host overhead。
- FlashInfer page=64，wrapper=`CUDAGraphBatchDecodeWithPagedKVCacheWrapper`；加速比均为 reference/treatment，大于 1 才表示治疗更快。
