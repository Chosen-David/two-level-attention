## 3. 各竞品接入门禁

- **Quest**：官方 quality 路径 dense prefill/前两层，decode 全QK再mask；高效路径才是页minmax索引与稀疏读取。Qwen3独立重写不自动成为vendor双证。b6782d8旧版 `qwen3_quest_patch.py` 缺dense分支、skip_first_layers未使用；4b0a25f新版已补分支，但decode复用旧Llama forward未执行Qwen3 q_norm/k_norm，全QK仍在。新测试预算大于当前序列却要求输出不同，不能证明稀疏正确；先核全预算等价与selector语义再验收。本任务不修改该实现。
- **ClusterKV**：accuracy在dense prefill之后首个decode建簇；高效路径可在prefill中异步建簇并与dense attention重叠。建簇不是稀疏prefill attention。保留sink/生成tail、CPU offload/簇更新口径；cavg/ccluster或替代kmeans不得标为官方vendor结果。依赖未就绪记blocked，不以自研替代充数。
- **FASA**：校准选频段、decode候选选择后回到完整维度attention；论文v3确有DeepSeek-V2-Lite-Chat部分RoPE/MLA质量实验，但固定源码入口只见llama/mistral/qwen映射，不能把R1-Distill等同原生MLA，也不能据此断言论文没做MLA。
- **SparQ**：稀疏decode、dense prefill；质量库GQA组共享选择与gpt-fast逐query-head选择不能混同；记录mean-V补偿开关及对应模型/论文设置，不强制所有模型开启。gpt-fast固定position重复计时不是完整自回归生成E2E。
- **MInference**：默认稀疏prefill、dense decode；其他decode KV插件不是MInference原始方案。Qwen3 pattern/适配须单独核实，不能从支持Qwen2推定已支持Qwen3。
- **MoBA**：wrapper等长Q/KV走sparse prefill/training，不等长走dense flash decode。不是“稀疏decode慢速fallback”，training-free直接插入不构成理论下界；保留训练条件。HiP须区分原论文实现、新版仓库和HEAL，未验收前保持条件候选。
- **MLA**：没有原生支持就记unsupported；自研MLA迁移是独立改造，不可用论文引用代替同模型实测格子。

## 4. Sanity与验收

每个方法×模型×路径标官方native / 已验证faithful port / 不支持或未验证(N/A)。Qwen3不能只换model名；已有字段映射计划不是验收。保护Q/K norm、RoPE、GQA、scale/mask/cache、阶段分支与dense fallback；全预算dense等价仅必要，真实选择器另对拍。官方Quest只注册Llama/Mistral；当前Qwen3 port暂未验收。无法低风险移植则Qwen3诚实N/A，可提出共同官方支持模型的配对补充，未经既有资源授权不扩矩阵。质量mask移植不等于高效kernel支持，禁止跨模型拼排行榜。

保留现有Qwen3结果，不直接全量换模型重跑。若多个核心对手需大幅移植，先据真实支持交集提出一个共同checkpoint作匹配补充/主比较；冻结我方规则参数，Qwen3保留跨模型验证，不重启大搜索。Llama具体版本/context/RoPE须逐仓核实，当前未选定新checkpoint；本条不新增下载/GPU排期。

支持交集独审：没有证据证明六个核心候选存在零改动共同checkpoint。Llama-3.1-8B-Instruct仅为待预检候选，Quest/ClusterKV高效路径及SparQ仍有版本/语义门槛。FASA Qwen2 adapter、MInference Qwen2/2.5配置不等于Qwen3；HiP有Qwen3-30B-A3B文档但该路线强制dense decode，不外推Qwen3-8B sparse decode。详见同一份advice的逐方法证据。当前vendor_baselines已公开，旧“未公开”快照不再代表现状。

先核身份/SHA、配置、模型前处理(GQA/q_norm/RoPE)、预算与保护区、mask/cache/位置、官方scorer与计时范围，再做已授权的近官方复现及移植对拍。异常差异须排查并记录；不得强制结果朝“稀疏掉点”方向或删除真实反例。与论文结论不同不自动判错；无法解释的结果标待核，不伪造验收。CPU小测试通过不代表GPU质量/性能通过。

我方prefill当前仅Qwen3有可选gate，Llama仍dense；eager_prefill全QK再mask且chunk末query共享选择存在前缀不变性待验证点。flag存在不等于严格因果、质量和性能验收通过。此处只是状态提醒，修法及冠军由Opus负责。
