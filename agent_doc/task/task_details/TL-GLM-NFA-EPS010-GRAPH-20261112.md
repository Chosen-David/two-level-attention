### r1 OOM根因

`decode_frozen_request` 的finally仅执行 `pool.release(runner)`，而该release只清空 `runner.scheduler`。每个请求使用独立Cache，session pool仍强引用对应GraphRunner；`static_logits` 又持有含 `past_key_values` 的输出，使旧KV arena和CUDA Graph私有池跨请求累积。日志显示单进程在2–5个请求后达到约106–140GiB；部分机器同时有他方进程，但r1自身独占格也复现同一泄漏，根因不是单纯共享显存。
