# E156 精筛候选化（阶段 0）交付报告

日期：2026-10-20 · 执行：deepseek 轨 · 状态：门禁全过 + e2e smoke 通过

## 目标（阶段 0）

`score_fine` 只对 L1 候选 token（≈K1·bs + sink + swa + bypass）打分，消除全宽
`[1,H,T]` fine 物化与全宽 einsum。验收：`test_e127_gates.py` 全过、预算拉满==dense
锚点、32K needle 正确、诚实 wall 记录。

## 实现（sparse_attn/indexer/tli_indexer.py）

### 1. 单源 L1 块选择 helper
`_select_l1_blocks(score_coarse, score_coarse_avg, S_real)` 抽取块级 topk
（e64 分区/单池/skip/E155b bypass），compute_score 与 compute_mask 共用同一实现，
杜绝两份口径漂移。

### 2. per-head 候选构建（E156b 修复）
初版用「所有 head 选中块并集」——多 head 下并集覆盖近全序列（32K 实测 27904/32768），
einsum 无省算且 nonzero/unique/sort 开销反超（+7×）。改为 **per-head 行矩阵**：
每个 kv-head 只对「本 head K1=128 块 + 强制区（bypass∪sink∪swa）」打分
（~8.5K/head vs 全宽 32K）。返回 q-head 空间 `[H,R_max]` + 每 head 实长
`cand_len[H]`（短序列/尾块截断 pad 时 scatter 用 cand_len 门控防 sentinel 污染）。

### 3. 向量化候选构建（E156c）
per-head Python 循环 = 8×~20 个小 CUDA launch ≈ 1ms host 开销（32K 实测
build_cand=1.04ms，占候选 compute_score 55%），且 batch 化后×B。改
`torch.nonzero(as_tuple=True)`（行优先天然按 head 分组、块升序）+ bincount +
cumsum + scatter 一次构建（1.04ms → ~0.05ms）。语义逐位等价（`/tmp/dbg_build_equiv.py`
n_bad=0 对拍验证）。

### 4. 重建修复（E156c 关键）
compute_mask 里重建 gate 原为 `score_fine.shape[-1] != S_width`——但候选矩阵列是
「候选秩」而非 token 索引（per-head 按 L1∪bypass∪sink∪swa 拼接），S=kt·bs 整块边界
时 R_max 恰等于 S_width（如 4096），旧守卫跳过重建 → 下游把候选秩当 token 索引 →
mask 错位。**cand_idx 存在即无条件 scatter 重建**（块∪强制区重复索引 scatter 幂等同值；
R_max<S_width 与 R_max==S_width 一视同仁）。

### 5. Triton 融合候选 kernel（E156c）
`_score_fine_cand_kernel`（非投影路径）：单 launch 内 cand gather（对角 GQA K 寄存器
复用，读带宽 /g）+ fp32 累加 + `-inf` 门控（`offs_r < cl`），替代
gather+repeat fp32 物化+einsum+where 链。门控对齐 `_fast_score_fine`
（非投影/紧凑 4D/连续末维/fp32 q/同维同头数）；异常 fail-closed 置 `_triton_ok=False`
并回退 einsum（值同）。

### 6. 测试口径修复（_ulp_ok）
候选化后 score_fine 的未选候选位置为 `-inf`（两臂同候选集 → 逐位相等），但
`-inf - (-inf) = nan` 污染全局 rel max（skip 层 R_max<<S_width 大量 -inf 时 rel 变
nan 误判 ULP FAIL）。修法：两臂 isfinite 布局必须逐位一致（不一致即真差异强制 FAIL），
相对幅度只对两臂均有限的位置计算。

## 诚实 wall 发现（B=1 Triton H20）

```
S=  32768: full score=0.220 mask=0.682 total=0.903 | cand score=1.160 mask=1.826 total=2.985 R=8448
S=  65536: full score=0.230 mask=0.700 total=0.930 | cand score=1.153 mask=1.826 total=2.979 R=8448
S= 131072: full score=0.269 mask=0.711 total=0.980 | cand score=1.143 mask=1.848 total=2.991 R=8448
```

- **全宽路径在 B=1 Triton 下已 flat（32K-128K 均 ~0.9-0.98ms）**——H20 并行能力把
  全宽 `[1,H,T]` 打分/softmax/topk 压得很低，非瓶颈。
- 候选化（score=1.16ms，Triton kernel 已把原 einsum 候选 1.327ms 压下来）在 B=1 无
  wall 收益；总耗时 2.98ms 反慢 3.3×，**瓶颈在 compute_mask 消费端仍做全宽 scatter
  重建 + 全宽 softmax/topk（1.826ms）**。
- **候选化的真实价值**：① 消除 einsum 回退路径的 O(T×H×d') 全宽物化（Triton 不可用/
  回退时省显存省算）；② 阶段 1 batch 化的地基——batch 下每行候选 R=8K vs 全宽 T=32K，
  `B×R` 物化远小于 `B×T`，批量 einsum 形状流 `bh d, bm h d -> b h m` 只有候选化才省算。

## 阶段 1 衔接建议

`gate_bs1_equiv`（batch=1 与旧入口逐字节一致）将同时覆盖候选化开关的 e2e 对拍。
