# DAC Best Paper 论文集（2017–2026）

按用户 2026-10-16 指令创建，供 DAC 论文学习与写作参考。近十年按 2017–2026 十届计算。
本目录仅收录 DAC Research Best Paper 正式获奖论文，不混入 Best Paper Nominee、Most Influential Paper、在 DAC 颁发的期刊奖或 ASP-DAC 论文。

**获奖名单已核实 13 篇；已下载 7 篇有效 PDF，另有 6 篇尚未取得全文。PDF 收集尚未完成。**
2017、2018、2023 年各有两篇，其余年份各一篇。

## 核查说明

- 2023 年 Gamora 与 RL-CCD 均获奖：[ACM SIGDA 2023 年 8 月公告，第 5 页](https://www.sigda.org/wp-content/uploads/2023/08/August-2023-SigDA-E-News.pdf#page=5)明确列出两篇。部分会议网页抓取结果只显示其中一篇，因此以该同期公告及 CEDA 名单交叉确认。
- 2025 年 INSTA 的获奖身份由 [NVIDIA 实验室公告](https://research.nvidia.com/labs/electronic-design-automation/)及[第一作者主页](https://yichen-lu.github.io/)共同确认；早期 GitHub README 仅写提名，不能据此漏收。
- DREAMPlace 保存的是 2019 年 6 页 DAC 论文；CEDA 条目混有 2021 年期刊扩展版书目信息，未以该期刊版替代。
- 已下载文件均通过 PDF 文件头、pdfinfo、全文 pdftotext 和首屏标题匹配检查；SHA-256 记录原始字节。未对这些论文做科学复现或全文审稿。
