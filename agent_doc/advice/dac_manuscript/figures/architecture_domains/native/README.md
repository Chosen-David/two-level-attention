Editable architecture object source. Run export.mjs with Node.js and @oai/artifact-tool available to regenerate one-slide native English/Chinese diagrams. Text, rectangles, and polyline/freeform paths are native; arrows are separate native triangles rather than auto-routed connectors. The integrated 17-slide PPTX is the presentation source of record. Its PDF can be rebuilt by a presentation application without this optional regeneration tool. Font metrics can vary by renderer.
