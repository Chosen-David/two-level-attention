# RULER 32K/64K descriptive comparison

Integrated as the main AVG figure and Supplementary Figure S8 (all 11 tasks). 32K source data are author-reported aggregates at fixed commit b5a97b314119006dc7e1624bf60268ff2501e44d; 64K data (E147h beta=.0625, E146c beta=.125, E119 FullKV anchor) come from commit 51b4679c52feebc5327775c660db41550b1c8782. inputs/provenance.json binds the original Git blobs. This is arithmetic and plotting, not model execution or raw prediction replay.

Run `MPLCONFIGDIR=/tmp/mpl-baseline python draw.py` with matplotlib, Pillow and the explicitly referenced Noto Sans CJK font. The integrated script uses PDF Type3 for Chinese and Type42 for English. Note: matplotlib >= 3.11 builds the PDF glyph-subset tracker from `ps.fonttype`, not `pdf.fonttype`, so draw.py sets both rcParams together; setting only `pdf.fonttype` raises `ValueError: bytes must be in range(0, 256)` on CJK text. Chinese Type3 glyphs render correctly across MuPDF and Poppler but are not reliably text-extractable; editable SVG and source text are retained. Compact figures are 7.1x2.1in, full figures 7.1x4.5in, minimum 7.5pt at native size; do not reduce to single-column width. Generated PDF container bytes can vary by environment.

AVG is the unweighted mean of all 11 task scores; task deltas explain heterogeneity, not a per-task acceptance gate. 32K uses beta=.0625 (8B) and beta=.125 (32B). Method labels encode page64/K1=128/K=1024/alpha=.25/gamma=.625/sink4/SWA128/cmp4, but gate status, actual scoring dimensions and realized selection identity remain unverified. FullKV is a dense quality reference, not an equal-budget sparse arm. 8B source-data hashes match but scorers differ and input identity is native versus legacy-partial. 32B manifests match source-data/scorer/producer/model configuration, but raw predictions remain unreplayed. Both 32K comparisons span machines. The 64K sparse arms share one machine; the E119 FullKV anchor comes from a separate run, and all three arms score zero on MultiKey-3. No paired CI, non-inferiority, causal mechanism or matched quality-cost benefit is established; no external sparse-baseline leaderboard is implied.
