Run `MPLCONFIGDIR=/tmp/mpl-baseline python draw.py` with matplotlib, Pillow and the bundled Noto Sans CJK font resolved relative to this package. 2026-10-23 (post-T6 fix): both languages now embed PDF Type42. The earlier zh Type3 path made pymupdf report Noto CJK char boxes at ~2.86em (21.4pt boxes for a 7.5pt face), failing the pt^2 area gate on every tight row (17/21 hard pairs in the compact/full zh PDFs); Type42, as already used by fig_o_observation.py, embeds the OTF subsets with normal bboxes and passes both gates. Note: matplotlib >= 3.11 builds the PDF glyph-subset tracker from `ps.fonttype`, not `pdf.fonttype`, so draw.py sets both rcParams together; setting only `pdf.fonttype` raises `ValueError: bytes must be in range(0, 256)` on CJK text. Compact figures are 7.1x2.6in, full figures 7.1x4.7in, minimum 7.5pt at native size; do not reduce to single-column width. Generated PDF container bytes can vary by environment.

AVG is the unweighted mean of all 11 task scores; task deltas explain heterogeneity, not a per-task acceptance gate. The 32K arm uses beta=.0625. FullKV is a dense quality reference, not an equal-budget sparse arm. 8B 32K source-data hashes match but scorers differ and input identity is native versus legacy-partial; the 32K comparison spans machines. The 64K sparse arms are reported on one machine; the E119 FullKV anchor comes from a separate run, and all three arms score zero on MultiKey-3. At 128K the beta reruns are same-machine, the dense anchor is a separate run, and the T6 champion is a single run at a different bs tier. No paired CI, non-inferiority, causal mechanism or matched quality-cost benefit is established; no external sparse-baseline leaderboard is implied.

The 64K manifests align recorded input IDs, answer hashes, lengths and source-data hashes. Sparse scoring hashes match, but prediction-generator and effective-configuration hashes differ. The dense anchor has legacy-partial identity, a different scorer and only operator-declared YaRN settings. Raw predictions were unavailable for replay; the 64K sparse arms use K=1024, not K512. FullKV is the dense reference without a sparse top-K cap.

**Glyph-gate acceptance (2026-10-23, after the Type42 switch).** Both detectors are now authoritative and both pass: the char-bbox ratio overlap detector (`exp/trace/check_glyph_overlap.py`, threshold 0.45) and the raw cross-span pt² area check each report 0 overlapping pairs on all four PDFs (en/zh x full/compact), with 0 out-of-page spans. The earlier zh Type3 renders needed a baseline-anchored visual-box exemption for the pt² check; that exemption is retired with the Type42 switch. Layout parameters (single-line subtitles and zh footers, 7.5pt ticks, Delta column at axes fraction 1.12, AVG line at -0.30, labelspacing=.8) should not be compressed further without re-running both gates.
