## FFD repair

The earlier guard accepted an externally supplied empty QuantizedKVCache without
checking the minimum prefill, and accepted cache settings unlike its recorded
configuration. The guard now tracks only caches it constructs, separately per
loader, and checks BS, k_bits, FP8 residual and capacity on the root and each
layer. External same-type/same-config caches are rejected. Empty accepted caches
still require >=128 tokens. Offloading is rejected.

Successful forwards bind the layer objects, complete layer count and sequence
length. A changed/replaced layer, divergent length or reuse after a failed model
call/route gate is rejected. The guard is not a cryptographic integrity check of
tensor contents. CPU test doubles exercise these boundaries; actual FFD CUDA
cache/kernel and HuggingFace generate compatibility remain unvalidated.

The two new cache regression methods fail against the exact previous guard
from `0fd6cac` (2 failures, 0 errors). Fifteen current baseline test methods pass
normally and under `python -O`; failure evidence is retained separately from
historical first-integration evidence.

[HISA: Efficient Hierarchical Indexing for Fine-Grained Sparse Attention,
arXiv:2603.28458v4](https://arxiv.org/html/2603.28458v4), COLM 2026.

`MuLabPKU/TransArch@dc9f3a3b7938bd26e165b0c99e3b6ea627d1ecfc`;
`HISA_COLM_2026/README.md` explicitly names the GPU reference kernels in

Fetched the kernel source at
`tile-ai/tilelang@7940102813c08c1a589e1b4c57d7010d9aa68982`, retaining its
MIT license text including its historical collaboration notice. The checked
example describes a **prefill indexer** pipeline: block means, coarse score,
block top-k, fine token score and token top-k. It consumes DSA indexer Q/K and
head weights and produces indices for Sparse MLA. This is not a Qwen3 attention
replacement and cannot be wired to current Qwen3 or DeepSeek-V2-Lite by merely
changing model names. No kernel executed. The author-linked end-to-end route
requires SGLang v0.5.11/CUDA13/TileLang0.1.9; not installed or modified under this
task's explicit exclusion. No HISA or SGLang code is redistributed here.
