## 1. MLA q·k 内积分解：内容项 + 位置项

MLA 每个注意力 head 的 logit（共 192 维内积，softmax_scale = 192^-0.5 × mscale²，yarn mscale(40,0.707)²）：

```
score_h(q_t, k_t') = ⟨q_nope^h(t), k_nope^h(t')⟩ + ⟨q_rope^h(t), k_rope(t')⟩
                     └── 内容项：128 维，无位置编码 ──┘   └── 位置项：64 维，MQA 共享单 k ──┘
```

**内容项（nope·nope）**：位置无关的纯内容相似度。q_nope 由 q_proj 直连（q_lora_rank=None）、k_nope 由 kv_b_proj 从 512 维 latent 上投影（per-head）。它回答「这个 key 在语义上像不像 query」。

**位置项（rope·rope）**：k_rope 是 64 维 MQA 共享向量（不经 latent，直接来自 kv_a_proj_with_mqa 尾段）。对第 j 个频率对（j = 0..31），旋转后内积可写成极坐标形式：

```
⟨q_rope, k_rope⟩ = Σ_j  |q_j(t)| · |k_j(t')| · cos( θ_j(t) − θ_j(t') )
```

其中 (q_{2j}, q_{2j+1})、(k_{2j}, k_{2j+1}) 各自构成第 j 频率的复数（幅度 |·| 由 token 内容决定、相位 θ_j(t) = t·ω_j 纯由位置决定）。**rope 项 = 各频率上「内容加权」的相对位置余弦和**——内容决定每维幅度，位置决定符号与峰值。单频内积对距离 d 的响应是 |q_j||k_j|·cos(d·ω_j)：频率 j 刻画一个特征长度 1/ω_j（波长）的位置感受野。

**尺度/频谱特性**：nope 128 维与 rope 64 维在 logit 中的方差贡献由权重谱决定（E141b 实测的 proxy 分解——rope64 臂 .769~.814 vs nope128 臂 .477~.826 vs full192 .815~.915——说明两者量级可比，rope 是主要选择信号源，4/5 层）。

## 2. rope 频谱结构：频率 → 维度映射的推导（从 pinned 源码）

### 2.1 通道布局（interleaved → halves 重排）

pinned 源码（modeling_deepseek.py sha256 `5128aab0...`，E141b 同源验证逐位一致）：

- `DeepseekV2RotaryEmbedding._set_cos_sin_cache`：`emb = cat((freqs, freqs), dim=-1)` → cos/sin 表是 halves 布局：**通道 j（0..31）与通道 j+32 用同一个频率 ω_j**，且 `inv_freq[j] = base^(−j/32)`（dim=64, base=10000）——j 越小频率越高。
- 探针端（e141 修复版，E141b 对拍逐位一致）：q_pe/k_pe 原始布局是 interleaved `[c_0, s_0, c_1, s_1, …, c_31, s_31]`，经 `reshape(T,H,32,2).transpose(-1,-2).reshape` 变为 halves `[c_0..c_31, s_0..s_31]` 以匹配 rotate_half + halves cos/sin。

**结论（E158 探针的维度语义）**：在重建后的 rope64 表示（探针的 qr/kr）中，
**维度 j（0..31）= 频率对 j 的 cos 分量，维度 j+32 = 频率对 j 的 sin 分量；频率 ω_j = inv_freq[j] 随 j 单调递减（j=0 最高频，j=31 最低频）。**

### 2.2 yarn factor 40 的影响（高频保留、低频插值）

config：`rope_scaling = {type: yarn, factor: 40, beta_fast: 32, beta_slow: 1, original_max_position_embeddings: 4096, mscale: 0.707, mscale_all_dim: 0.707}`。源码公式：

```
low, high = correction_range(beta_fast=32, beta_slow=1, dim=64) = (10, 23)   # 实算
mask(j)   = 1 − ramp(j; low=10, high=23)          # j≤10 → mask=1；j≥23 → mask=0
inv_freq[j] = freq_inter[j]·(1−mask) + freq_extra[j]·mask    # freq_extra=原始频率；freq_inter=原始/40
```

即 **j ≤ 10（高频 11 对）保持原始频率（保局部分辨率，yarn 论文的 extrapolation 段）；j ≥ 23（低频 9 对）频率 /40（插值段，把最长波长从 ~9.3K 拉到 ~300K token 以覆盖 163840 上下文）；j = 11..22 线性过渡**。mscale(40, 0.707)/mscale(40, 0.707) = 1.0，无额外缩放。

精确频率表（本设计脚本实算，与源码公式逐项一致）：

| 频段 | pair j | 波长（token） | 64-token 块内相位变化 δ=64ω_j |
|---|---|---|---|
| 高频（原始保留） | 0..10 | 1.0 → 17.8 | 64 → 3.6 rad |
| 过渡段 | 11..13 | 25.6 → 54.4 | 2.5 → 1.18 |
| 中频 | 14..16 | 80 → 182 | 0.80 → 0.35 |
| 中低频 | 17..22 | 281 → 5623 | 0.23 → 0.011 |
| 近恒定（/40 插值） | 23..31 | 30K → 300K | ≤0.002 |

**关键发现（修正直觉）**：yarn factor 40 把低频 9 对（j≥23）压到 16K 序列上近乎恒定——整条序列的绝对相位 t·ω_j 在 t=16384 时也仅 0.55 rad（j=23）到 0.055 rad（j=31）。这些维度对 token 排序的区分度趋零（k_j 向量对所有 token 几乎相同 → 内积贡献近似常数偏置），但**无害**：常数不扰动排序。rope64 里真正携带可变位置信号的是 j = 0..22 这 23 个对（46 维）。

### 2.3 维度映射结论（E158 探针臂定义依据）

- **低频 32 维**（假说④）= 频率对 j = 16..31 = **维度 {16..31} ∪ {48..63}**。其中 j=16..22（14 维）是块统计友好的活跃信号（波长 182~5623），j=23..31（18 维）近恒定、几乎零贡献。
- **高频 32 维**（对照）= 频率对 j = 0..15 = **维度 {0..15} ∪ {32..47}**。全部 32 维活跃（波长 1~120），但块内震荡剧烈。

（结构上与 E140 Qwen 128 维 rope 的 tail32=[48,64)∪[112,128) 同构：同样是「低半频率对」口径。）

## 3. 块级粗筛（bs=64 池化）视角下各维度的行为

TLI 的 L1 粗筛用 64-token 页的池化统计。对 rope 维 j，页均分对线性相位余弦的衰减是经典 sinc 包络：

```
衰减系数 ≈ sin(δ/2)/(δ/2)，δ = 64 · ω_j（块内总相位跨度）
```

- **高频 rope 维（j=0..10，δ=3.6~64）**：页均分后信号衰减到 <10% 甚至反号——**avg 池化天然抹平高频**。min/max 封络（生产 far-minmax 用的）保留块内峰值相位匹配，仍有区分度。token 级 L2 精筛不受影响（无池化）。
- **中低频 rope 维（j=11..22，δ=0.011~2.5）**：块内缓变，页均分 ≈ 连续值，**avg 池化基本无损**——这是块级粗筛的甜点频段。
- **近恒定维（j=23..31）**：页均分前后无差别，近似常数偏置，无区分度也无噪声。
- **nope 维（128 维，无位置结构）**：块统计 = query 与「块平均内容向量」的内积——语义寻址的天然块特征。但 E141b 已证 nope 随机 32 维 ≈ 全 128 维（±0.03）→ nope 谱平坦、维度高度冗余，**压缩无损**。

**预测（可检验）**：
- P1：`rope_lowfreq32` 的 L1 页召回接近 `rope64`（甜点段 j=16..22 全在低频半段，其余维近恒定无害）；
- P2：`rope_highfreq32` 的 L1 页召回显著劣化（j=0..10 被 avg 抹平，64 维中仅 j=11..15 约 10 维存活），但 L2（页内 token 排序）相对较好——页召回/选中重合两指标出现**频谱学分离**；
- P3：`nope_first32` ≈ `nope_last32` ≈ `nope32r` ≈ `nope32hi`（谱平坦 → 无结构分化；first32 是结构假说的对照靶）；
- P4：混合 96 维臂（`rope64_nope32f/hi`）逼近 `full192`——rope 提供位置先验 + nope 子集补内容项，Δ 缺口（E141b 里 rope64 与 full192 差 .022~.159）应大部分被填补；
- P5：L12（nope 反转最强层）上混合臂收益最大（内容项主导的层恰好由 nope 分量补足）。

## 4. 候选子空间设计假说（对照任务指令五假说）

| 假说 | 内容 | 探针臂 | 数学预测 |
|---|---|---|---|
| ① 仅 nope | 只用内容地址 | `nope128`（锚，E141b 已有） | 已被 E141b 驳回（4/5 层远弱于 full），保留作锚复核 |
| ② nope 前 32 | 结构化 nope 子集 | `nope_first32`（维 0..31） | 与 ③ 无显著差（谱平坦）；若显著则 nope 存在位置偏序结构 |
| ③ nope 随机 32 | 维度冗余论 | `nope32r`（seed 20261002） | ≈ nope128（E141b 32 维结论复测） |
| ④ rope 低频 | 位置地址粗筛化 | `rope_lowfreq32`（{16..31}∪{48..63}） | L1 友好（P1）但 L2 缺高频细节；与 `rope_highfreq32` 对照出频谱分离（P2） |

**设计原理总结**：MLA 索引器的最优子空间 = **rope 全维（位置先验，其中 j=11..22 是 L1 有效频段、j≥23 无害冗余）+ nope 低秩内容补丁（32 维足够，因 nope 谱平坦）= 96 维混合**；纯单分量（nope-only / rope-only-32）均非充分。

## 5. E141b L12「nope 反转最强」的层异质性：解释与利用

E141b 实测：L12 上 nope128（.826）> rope64（.756），其余层 rope 优势。解释路径：

1. **深层语义 key 方差结构**：中后层（MoE 块更密集处）的 k_nope 上投影方向谱可能集中到少数内容方向 → head 均值概率质量更多由内容相似度决定；rope 的位置余弦在同层被 nope 大方差稀释。
2. **MLA 解耦表征假设**：nope128 承担「检索式内容匹配」（hotpotqa/musique 是实体桥接任务，深层实体语义），L12 附近可能是语义压缩-检索的过渡层。
3. **利用方式**：
   - 逐层自适应预算：浅层偏 rope（L1 可只用 rope 中低频），L12 附近把 nope 混合权重提高——E158 的 96 维混合臂若在 L12 收益最大（P5），支持「层聚类分段配置」而非全层统一；
   - 但工程上单索引共享（MQA latent）倾向统一子空间——若混合臂跨层稳定逼近 full192（worst-case 而非 mean），则统一 96 维即可，无需逐层配置。判据看 verdict 的 mean 与 worst 双口径。
